## 📦 Installation

Follow these steps to set up ALMEER MUSIC locally:

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- MongoDB

### Step-by-Step Guide

1. **Clone the repository**
```bash
git clone https://github.com/SIDER44/ALMEER-M2.git
cd ALMEER-M2
```

2. **Install dependencies**
```bash
npm install
# or
yarn install
```

3. **Set up environment variables**
```bash
cp .env.example .env
# Edit .env with your configuration
```

4. **Start the development server**
```bash
npm run dev
# or
yarn dev
```

5. **Open your browser**
```
http://localhost:3000
```
